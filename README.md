# Prompthub

**Prompthub** is a complete AI Prompt Marketplace web application built as a Decentralized Application (dApp) on the Stacks blockchain, secured by Bitcoin.

## 🌟 What is Prompthub?

Prompthub is a Web3 decentralized marketplace that allows true ownership and monetization of AI creativity. 

At its core, **Prompthub is a dApp designed for selling AI prompts and showcasing the high-quality results generated by those prompts.** 

Whether you are a Prompt Engineer looking to monetize your finely-tuned commands for Midjourney, ChatGPT, or Stable Diffusion, or a Creator looking for the perfect prompt to achieve a specific aesthetic, Prompthub provides the platform to securely trade these digital assets using crypto (STX or sBTC).

## 🚀 Key Features

*   **Buy, Sell, and Trade Prompts**: A vibrant marketplace for AI prompts across various categories (Image Generation, Text, Code).
*   **Showcase Results**: See what a prompt can actually do before you buy. Prompthub emphasizes displaying the *results* of the prompt alongside the listing.
*   **Web3 Native**: Built on the Stacks blockchain. Login with your Stacks wallet (like Leather or Xverse) - no emails or passwords required.
*   **Crypto Payments**: Support for transactions using Stacks (STX) directly on the testnet/mainnet, with planned support for sBTC.
*   **Decentralized Authentication**: Built-in verification via cryptographic Message Signing to prove wallet ownership before transactions.
*   **Neobrutalist Design**: A striking, modern UI featuring a blend of dark mode, sharp neobrutalism, and clean glassmorphism tailored for the Web3 aesthetic.

## 🛠️ Tech Stack

*   **Framework**: [Next.js](https://nextjs.org/) (App Router)
*   **Styling**: [Tailwind CSS](https://tailwindcss.com/) with custom Neobrutalist components
*   **Web3 Integration**: 
    *   `@stacks/connect` for wallet connections and STX transfers
    *   `@stacks/encryption` for cryptographic message signing and user authentication

## 🚀 Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 💳 Wallet Setup

To fully interact with Prompthub (creating listings, buying prompts), you will need a Stacks-compatible Web3 wallet:
1. Download [Leather](https://leather.io/) or [Xverse](https://www.xverse.app/).
2. Switch your wallet network to **Testnet** if you wish to test fake transactions without spending real STX.
3. Use the "Connect Wallet" button in the navigation bar to sign in.
